# C#-oefeningen

Deze map bundelt de programmeeroefeningen uit verschillende hoofdstukken en herhalingsreeksen. De repository bevat ongeveer 500 solutions, van kleine consoleoefeningen tot grotere projecten met domein-, persistentie- en presentatielagen.

## Onderwerpen

- Variabelen, invoer, berekeningen en conditionele logica.
- Lussen, methodes, arrays, strings en datums.
- Objectgeoriënteerd programmeren, collecties en LINQ.
- Domeinmodellering, repositories, console-interfaces en unit tests.
- Grotere cases zoals bier-, garage-, fitness-, film- en bushaltebeheer.

## Uitvoeren

Open de gewenste `.sln` in Visual Studio of voer vanuit de projectmap uit:

```powershell
dotnet run --project .\NaamVanHetProject.csproj
```

Niet alle oefeningen zijn zelfstandige eindproducten. Sommige zijn bewust klein, behandelen één leerdoel of bestaan in meerdere varianten om verschillende oplossingen te vergelijken.
